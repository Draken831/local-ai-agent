## Merge policy

The uploaded Windows package identified itself as v1.0.0 and launched the CLI by default. The GitHub baseline already contained newer v1.2.0 requirements:

- strict cloud-first provider order;
- short failover timeouts/circuit breaker;
- GUI as the default application interface;
- 97 curated quick answers.

The update therefore uses the existing v1.2.0 runtime as the base and merges the uploaded project's non-regressive additions.
